# Hover Button Collection

A curated collection of button components featuring smooth hover animations built purely with Tailwind CSS.

## 📖 Overview

A library of UI button components designed with a wide variety of hover effects. This project was created to explore the full capabilities of Tailwind CSS and master complex utility-first styling and animation techniques.

- **Live Demo:** [https://hover.ukyo.me](https://hover.ukyo.me)

## ✨ Features

* **Pure Tailwind Animations:** Lightweight, smooth hover effects implemented exclusively using Tailwind CSS without relying on external animation libraries.
* **[WIP] Refactoring & Quality:** Ongoing refactoring of the source code to maximize maintainability, readability, and component reusability.

## 🛠 Tech Stack

* **Frontend:** React, TypeScript
* **Styling:** Tailwind CSS

## 🚀 Getting Started

### Prerequisites

* Node.js
* npm / yarn / pnpm

### Installation & Local Setup

```bash
# Clone the repository
git clone https://github.com/JunyaUkyou/hover.ukyo.me.git

# Navigate into the project directory
cd hover.ukyo.me

# Install dependencies
npm install

# Start the development server
npm run dev
